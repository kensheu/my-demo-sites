# My Demo Sites

展示用測試頁面，整合三個系統的統一導覽介面。

## 線上網址

https://kensheu.github.io/my-demo-sites/

## 系統架構

全站透過 `shared-nav.js` / `shared-nav.css` 注入統一頂部列與左側邊欄，支援三個系統切換：

| 系統 | 說明 | 頁面 |
|------|------|------|
| 內部後台 | 採購／管理人員使用 | 首頁儀表板、公告管理、餐點管理、餐點異動紀錄、店家異動審核、菜單排程管理、菜單排程管理 V2、菜單排程管理 V3、菜單排程管理 V4、菜單發布管理、菜單管理異動紀錄、菜單模板管理、各廠菜單、廠域QA、供餐價格設定、訂單管理、客訴管理、帳號管理、日報表、日報表 V2、日報表 V3、問題單&ECR、點數 & 折價券管理 |
| 店家後台 | 餐廳店家使用 | 公告通知（含排程通知、排程修改通知）、餐點管理、訂單明細、供餐設定 |
| 訂餐前台 | 訂餐會員使用 | 公告通知（含據點切換）、點餐、點數 & 折價券、訂閱方案、我的訂單、我的客訴 |

左側邊欄「首頁」群組可展開，包含：首頁儀表板、公告管理（採購首頁與美編首頁僅在直接瀏覽時顯示於側邊欄，不列於展開項中）。「餐點管理」群組可展開，包含：餐點管理、餐點異動紀錄、店家異動審核。「菜單管理」群組可展開，包含：菜單排程管理、菜單排程管理 V2、菜單排程管理 V3、菜單發布管理、菜單管理異動紀錄、菜單模板管理、各廠菜單、廠域QA、供餐價格設定。「問題單&ECR」同樣為可展開群組，子項目包含：📝 新增問題單、📋 問題清單、🔄 新增 ECR、📑 ECR 清單、📖 填寫指南。點擊子項目就地切換頁內 tab，無須重新載入頁面。店家後台左側邊欄包含：公告通知、餐點管理、訂單明細。

手機版（< 768px）：頂部列收合為 hamburger 選單，左側邊欄隱藏。

## 功能需求清單

> 各頁面皆須附有填寫指南，說明欄位規範與注意事項。
> 所有頁面須支援 RWD，針對手機版面進行優化。

### 首頁儀表板

- 統一各部門首頁框架，依角色顯示不同內容
- 角色切換下拉（讀取帳號管理的角色清單，fallback 為靜態預設清單；不含主管角色）
- **KPI 指標**（依角色預設，固定不可自訂；label 顯示於數值上方）：
    - Admin：全部指標
    - 營運：未讀公告、待處理客訴、今日訂單量總計、銷售毛利總計、熱門店家（顯示名稱）、熱門餐點（顯示名稱）
    - 採購：未讀公告、待審核異動、本週即將生效、本月有異動餐廳、本月新增品項
    - 行銷：未讀公告、會員總點數、待使用折價券張數、訂閱人數（動態從 sessionStorage 讀取）
    - 美編：未讀公告、新店家、待審圖片、可製作 EDM
    - 業務：未讀公告、待處理客訴、待定店家（續約）、待定客戶（續約）、店家營業額（月）、客戶營業額（月）、待定新專案、其他待處理
    - IT：未讀公告、問題單通知、ECR 通知
    - 人資 / 會計 / 司機：未讀公告
- **常用功能**（依角色預設，使用者可透過「✦ 自訂版面」調整；標題列標注「＊可於右上『自訂版面』設定」）：
    - 自訂結果儲存於 sessionStorage（`dashboard_config_v1`），按角色各自保存
    - 自訂 Modal 說明文字標注「清單中只會顯示有權限的功能」；可勾選項目依帳號管理角色權限過濾（`permissions_roles_v2`），無對應權限的功能不出現；若尚未讀取帳號管理資料，以各角色靜態預設清單作為 fallback
    - 重置預設
- **公告區塊**：Tab 切換（全部 / 未讀 / 系統公告 / 活動資訊）；點擊公告列開啟詳細內容 Modal 並標記已讀；超過數筆顯示滾動條
    - 部分公告設有角色限制（`roles` 欄位），僅顯示給指定角色；無 `roles` 欄位則全角色可見
    - 採購：顯示「店家異動審核通知：待審項目」
    - 美編：顯示「店家異動審核通知：待審圖片」

### 美編首頁

- 三個待處理事項區塊，各含左側 KPI 數字卡（rgb(0,193,215)）與右側列表（超過 4 筆顯示滾動條）：
    - **新店家**：列出新進店家與品項數量、預計使用月份，可刪除通知；依預計使用月份正序排列
    - **待審圖片**：列出待審核圖片申請，顯示店家、數量、預計使用月份、申請日期；點擊任一列跳至「店家異動審核」並自動篩選圖片類；依申請日期正序排列
    - **可製作 EDM**：列出可製作的 EDM 通知，顯示年月、廠區、發布時間，可刪除通知；依發布時間正序排列
- 內部公告區塊：Tab 切換（全部 / 未讀 / 系統公告 / 活動資訊）；點擊公告列標記已讀（透明度降至 30%）；超過 4 筆顯示滾動條

### 公告管理

公告分類：系統公告、活動資訊、其他（可透過 ⚙ 管理分類新增自訂分類）。

- **公告通知（各系統接收端）**：
    - 查看全部公告，可依全部 / 未讀篩選
    - 標記已讀
    - 店家後台：三種通知類型（系統公告 / 排程通知 / 排程修改通知），使用列表式樣式；各類型有對應標籤 badge
        - 排程通知：整合型批次通知（一次排程更新 = 一筆），詳情內可一頁看完所有廠區 / 日期 / 餐期 / 品項 / 份數
        - 排程修改通知：含異動摘要（移除品項、數量調整），詳情內逐日顯示修改前後差異
- **公告管理頁面（僅內部後台）**：
    - 新增公告，包含：標題、分類（下拉選擇）、彈出通知、顯示位置（複選）、內容、圖片、附件
    - 顯示位置垂直排列，各勾選項目有對應次選單：
        - 內部後台：無額外選項
        - 店家後台：勾選後展開**店家多選下拉搜尋**（未選任何店家 = 全部店家）
        - 訂餐前台：預設勾選，展開**廠區多選下拉搜尋**（未選任何廠區 = 全部廠區）
    - 可設定排程（發布時間、到期時間）
    - 公告狀態：發布中、草稿、排程待發、已到期
    - 搜尋標題、依分類 / 狀態 / 顯示位置篩選
    - 編輯、刪除公告
- **分類管理（⚙ 管理分類）**：新增自定義分類、點擊改名、刪除（有公告時阻擋）、拖移排序

### 餐點管理

- 可搜尋餐廳選擇器（旁顯示抽成 % chip，hover 顯示「來自客戶／供應商管理的合約設定」說明）
- 販售中 / 下架存檔區兩個 Tab
- 品項列表：料號、餐點名稱（含英文名稱、機台顯示名稱標注）、分類、店內價、終端價、成本價、摩寶連結狀態
- 店內價預約調整：有調升（紅 ↑）/ 調降（綠 ↓）顏色區分；成本價欄同步顯示「↕ 日期 自動更新為 $XX」
- 預約調整店內價：設定新店內價與生效日，系統於生效日自動套用並重算成本價，不需人工操作
- 終端價：可手動設定，與店內價獨立
- 清單 / 圖片切換檢視：
    - 清單模式：表格顯示，含料號、餐點名稱（英文名稱、機台顯示名稱）、分類、店內價、終端價、成本價、內部備註、摩寶狀態
    - 圖片模式：3 欄格狀卡片，顯示大圖、品名、英文名稱、機台顯示名稱、介紹（含欄位標籤）、三種價格、備註；hover 圖片區出現「上傳圖片」/「更新圖片」按鈕
- 圖片管理：
    - 單張上傳：於圖片模式卡片 hover 後點擊按鈕，或在編輯 modal 中上傳；編輯 modal 中可下載目前圖片
    - 批量上傳：選取多張圖片，檔名以品項名稱開頭（如 雙拼便當_1.jpg）自動對應品項
    - 批量下載：下載目前篩選結果中有圖片的品項，打包為 ZIP（示意）
    - 圖片放大檢視：圖片模式卡片圖、編輯 modal 縮圖均可點擊放大，支援 ESC 或點擊背景關閉
    - 疊加圖片設定：可勾選蛋奶素、僅供參考、截角圖（透明）、隨機出貨一款等標示圖疊加在餐點圖片上，套用後圖片模式所有有圖片的品項即時顯示疊加效果
- 新增 / 編輯品項：
    - 餐點完整名稱（無字數限制）
    - 機台顯示名稱（9 字上限，選填，留空自動截取）
    - 分類（下拉選擇，選項來自分類管理）
    - 排序（必填，新增時自動建議目前最大值 +1）
    - 英文名稱、介紹（顯示於訂餐前台）、內部備註（僅浩華人員可見）
    - 圖片上傳（單張，直接生效，無審核流程）
- 刪除品項（權限確認提示）
- 下架移至存檔區 / 重新上架
- 分類管理（⚙ 管理分類）：
    - 各餐廳獨立分類清單
    - 新增自定義分類、點擊改名、刪除（有品項時阻擋）
    - 拖移調整分類顯示順序
    - 儲存時自動同步品項的分類名稱
- 摩寶整合：
    - 未連結品項顯示「上傳摩寶」按鈕
    - 已連結品項顯示「已連結」badge、最後同步時間、「更新摩寶」按鈕（覆寫摩寶系統資料）
    - 圖片模式卡片底部同樣顯示摩寶狀態與操作按鈕
- 品項料號自動以現有最大號碼遞增，確保不重複
- Excel 匯入 / 匯出（示意）
- 分類篩選（顯示所有已定義分類）、搜尋品名或料號

### 餐點調價歷史紀錄

- 可搜尋餐廳選擇器
- 月份切換（上 / 下一月）
- 價格快照頁：
    - 顯示當月全部品項完整價格清單
    - 欄位：料號、餐點名稱、店內價、終端價、成本價（ℹ 成本價 ＝ 店內價 × (1 − 抽成%)）、異動標記
    - 異動標記：新增、異動、已下架、無異動
    - 統計數量（共幾筆、各標記數量）
- 月份快照異動備註自動產生：
    - 系統自動比對上月同料號資料，產生異動說明（品名異動、成本/售價調漲降、終端價異動、新增品項、已下架）
    - 多項異動以「・」連接，不需人工填寫
- 異動事件紀錄頁（流水帳）：
    - 依日期分組呈現每筆異動，顯示異動前後的值
    - 每筆紀錄包含：料號、餐點名稱、異動描述、日期、時間、操作人員、來源（人工操作 / 系統自動）
    - 依異動類型篩選（店內價異動、品名異動、上下架 / 新增）
    - 搜尋品名或料號

### 店家異動審核

- 可搜尋餐廳選擇器
- 待審核 / 已處理兩個 Tab
- 每筆異動顯示異動前後欄位比對（刪除線 vs 綠字）
- 店家須附上紙本菜單照片作為佐證
- 通知機制：任何異動申請送出後通知營運；審核通過或退回後亦通知營運
- 圖片類異動由美編審核，其餘（完整名稱 / 介紹 / 店內價）由採購審核
- 核准：可設定系統生效日期後確認寫入
- 退回：須填寫退回原因通知店家
- 篩選：依餐廳、異動類型（完整名稱 / 介紹 / 圖片 / 店內價）
- 菜單更新通知：店家可透過上傳實體菜單照片的方式申請異動，於審核端顯示為獨立通知類型

### 菜單排程管理

- 月曆導覽：點左右箭頭切換月份；點月份標籤開啟跳月視窗，可輸入年份 + 選月份或點快速捷徑直接跳至指定月；點「回到今日」回到當前月份
- 廠區下拉支援關鍵字搜尋，切換後月曆顯示對應廠區排程
- 餐期下拉可切換（全部 / 早餐 / 午餐 / 下午茶 / 晚餐 / 宵夜）
- 新增店家：開啟後頂部顯示當前廠區、日期、餐期（唯讀）；由當前篩選餐期決定餐期（無需重複選擇）；可選擇套用模板（選填），套用後餐廳下拉僅顯示模板內的店家池，不套用則顯示全部餐廳；可搜尋選擇餐廳；若餐廳有分店則分店必填；勾選品項後展開設定欄（成本價唯讀顯示、終端價可修改、櫃位（溫度：熱櫃/冷櫃；格號：不指定/A櫃/B櫃/C櫃，各自獨立單選）、線上可預約數預設 30、線下可預約數、店家預定數，數量欄位獨立一行），支援全選 / 取消全選；品項清單支援即時關鍵字搜尋
- 月曆節日標註：台灣固定國定假日（元旦、和平紀念日、兒童節、勞動節、國慶日、行憲紀念日）於對應日期格子中顯示紅色小標籤，每年自動套用無需維護
- 月曆 Chip 快速預覽：滑鼠移到月曆格子中的店家 chip 或會議便當 chip 時，就地彈出提示視窗，顯示餐期（含顏色標示）、店家名稱、各品項名稱及終端價，無需捲頁即可瀏覽摘要
- 日期明細：點月曆格子展開當天所有排程卡片，品項顯示成本價（橘色）與終端價，可直接編輯各品項的終端價、櫃位（溫度與格號各自獨立單選）與數量（數量三欄獨立一行），支援移除品項 / 移除整間店家 / 追加品項
- 防呆規則：跨廠區同日**同餐期**同餐廳衝突偵測（灰色不可選 + 衝突提示）；不同餐期可使用同一餐廳（A廠午餐已排 → B廠晚餐仍可選同餐廳）；餐廳公休日不可排程（依餐期判斷）；設定「可多廠區同時供餐」的餐廳，衝突改為橙色提示且仍可選取
- 排程狀態流程：entry 具備四狀態（暫存→審核中→審核完畢→已發布），透過月曆勾選日期後依序點擊「傳送給店家」→「模擬審核完畢」→「發佈訂餐」推進；各按鈕旁顯示勾選天數計數徽章，無勾選時點擊顯示提示
- 排程發布狀態：每間店家卡片顯示四狀態 badge（暫存 / 審核中 / 審核完畢 / 已發布），發布後有修改可點「取消變更」還原至上次發布狀態（附二次確認）；若改回原始值狀態自動恢復為已發布
- 複製整月排程：一鍵將當前廠區當月所有排程（含所有餐廳、餐期）複製到其他據點，重複者自動略過；目標據點支援關鍵字搜尋複選
- 分店選擇：新增店家時，若餐廳有多家分店可進一步選擇分店，分店必填；店家排程卡片顯示分店（藍色 badge）、廠區名稱、發布日期
- 批次調整價格：toolbar 提供「批次調整價格」按鈕（整月）；詳細面板批量操作列另有同名小按鈕（當天）；支援固定金額（±元）或百分比（±%），套用前預覽原價與新價（含 ≤0 警告），套用後可一鍵還原

### 菜單排程管理 V4

在 V3 基礎上以「餐期服務編號」取代廠區／供餐方案／餐期三個獨立下拉，簡化工具列操作流程。

#### 餐期服務編號

- **格式**：`{據點編號}-{訂單類型}-{餐期}`，例如 `A001-R-L`
- **據點編號**：自由輸入，例如 A001、A002
- **訂單類型**：`R`（一般訂單）、`S`（特殊訂單）
- **餐期**：`B`=早餐、`L`=午餐、`D`=晚餐、`N`=宵夜、`T`=下午茶
- 輸入框具備**自動完成**：根據輸入前綴即時篩選靜態服務編號清單（未來可改接 API），下拉選取後自動填入
- 輸入格式合法後，輸入框右側自動顯示三個解析徽章：**據點：A001**、**類型：一般訂單**、**餐期：午餐**

#### 新增按鈕邏輯

- 服務編號格式**不完整**時，月曆格與 detail panel 的「新增店家」按鈕 disabled
- 訂單類型為 **S（特殊訂單）** 時，**同時顯示「新增店家」與「新增會議餐」兩個按鈕**
- 訂單類型為 **R（一般訂單）** 時，只顯示「新增店家」

#### scheduleData 結構變更

- V3：`scheduleData[siteId][dateStr]`
- V4：`scheduleData[serviceCode][dateStr]`（以完整服務編號為 key）

### 供餐價格設定

設定各餐廳分店加價或折扣販售規則的管理頁（`menu-pricing.html`），完成後規則顯示於下方列表。

- **Step 3 — 設定定價模式**（三個子步驟）：
    - **S1 — 設定保障金額**（必填）：輸入最低終端價（元）；終端價低於此值時系統自動採用保障金額

        - 「單品加價」：**各餐廳分別展開**（accordion），逐品項獨立設定加價金額；品項依選取的餐廳動態產生，不同餐廳的品項分組不混合

        - 「全品項打折」：**各餐廳分別設定**折扣%數（1～99），即時顯示每間餐廳的折後價示例
        - 「單品打折」：**各餐廳分別展開**（accordion），逐品項獨立設定折扣%數（1～99）
        - **防呆**：折扣以「加價後終端價」為計算基準；若折後價低於保障金額，即時顯示橘色警示（系統將自動採用保障金額，不阻擋提交）

- **已設定的價格規則**（送出後顯示於頁面下方）：
    - 每筆規則一行橫向顯示：套用據點 badge、精簡摘要（保障金額、加價方式、有無折扣）、最後變動人員與時間
    - 右側：啟用狀態 toggle（預設停用）、編輯、刪除
    - **編輯**：點「編輯」按鈕後，規則資料回填至表單（步驟 1/2 選取、S1/S2/S3 各欄位），頁面頂部顯示橘色「編輯模式」提示列，送出按鈕改為「確認更新」；儲存後原規則原地更新（保留啟用狀態）；可點「取消編輯」或「清除重填」放棄變更
    - 篩選列：公司下拉、據點下拉（依公司聯動）、定價模式按鈕組（所有/純加價/加價＋折扣）、啟用狀態按鈕組（所有/啟用中/已停用）

### 日報表

每日各據點財務彙總報表（`daily-report.html`），以三層架構呈現應收、應付與利潤數字。

**第一層：日期總攬**
- 工具列：日期區間選擇（起 ～ 訖），預設「前一日減五日 ～ 前一日」（共 6 天），含查詢按鈕
- 列表依日期由新至舊排序
- 欄位：日期、星期、總應收、應收扣款、總應付、應付扣款、實際應收、實際應付、利潤、狀態、操作
- **計算規則**：財務欄位（總應收等）只加總狀態為「完成」的據點；實際應收 = 總應收 − 應收扣款；實際應付 = 總應付 − 應付扣款；利潤 = 實際應收 − 實際應付
- **狀態**：以綠燈（完成數）/ 黃燈（未完成數）複合燈號顯示當日據點完成情形
- **操作**：「編輯」按鈕；若未完成數量為 0 則按鈕變灰停用；點擊後進入第二層，帶入該日期

**第二層：各據點總攬**
- 工具列：日期選擇（帶入第一層選定的日期）、查詢按鈕、返回按鈕
- 欄位：餐期、服務編號、應收、應收扣款、應付、應付扣款、實際應收、實際應付、利潤、狀態、操作
- 狀態：完成（綠）/ 未完成（黃），預設「未完成」
- 操作：「編輯」按鈕；狀態為完成時按鈕變灰停用；點擊後進入第三層

**第三層：據點明細**
- 以「出餐日期」（完成交易日）為依據，列出每筆訂單明細
- 欄位：訂單編號、出餐日期、公司/據點、餐點名稱、數量、單價、小計應收、成本、小計應付、扣款、利潤、備註
- 底部合計列：合計應收、合計應付、合計扣款、利潤
- 提供「標記為完成 / 取消完成」按鈕（Demo 互動用，切換狀態後影響上層顯示）

**通用特性**
- 麵包屑：日報表 › 日期 › 據點・餐期，各層可點擊返回
- 利潤正值以綠色顯示、負值以紅色顯示

- 應收扣款、應付扣款、人力補助、車資補助從服務層級下放至**訂單層級**，每筆訂單各自記錄

- 表格欄位：店家、品項、數量、終端價、應收金額、應收扣款、成本價、應付金額、應付扣款

### 問題單與 ECR 請求

- 通知機制：
    - 新問題單提交後，IT 工程師需收到通知
    - 問題單狀態更新或回填後，填寫人需收到通知
    - 新 ECR 提交後，主管需收到審核通知
    - ECR 審核結果出爐後，填寫人需收到通知
- 範本功能（可行的話）：
    - 問題單與 ECR 皆支援儲存為範本，下次可快速套用常用欄位

- 問題單 — 填寫區：
    - 必填欄位：
        - 部門、填寫人
        - 專案名稱、模組
        - 問題摘要
        - 嚴重程度（嚴重 / 高 / 中 / 低）
        - 問題類型（程式錯誤、資料錯誤、畫面異常、效能問題、版面問題、規格異動）
        - 哪一支網頁 / 程式、發生時間
        - 進行了什麼操作（操作步驟）
        - 發生了什麼問題（實際結果 vs 預期結果）
        - 以前有沒有發生過？
        - 其他人有沒有發生過？
        - 作業系統、瀏覽器
    - 選填欄位：裝置型號、正常環境資訊、重現步驟、測試資料、截圖 / 錄影附件
- 問題單 — 清單區：
    - 搜尋、嚴重度、狀態篩選
    - 統計數量顯示（全部、待處理、處理中、已解決）
    - 編輯、刪除問題單
    - IT 工程師回填：問題原因、修復方式
- ECR — 填寫區：
    - 必填欄位：
        - 專案名稱、模組
        - 申請日期、部門、填寫人
        - 變更標題
        - 變更類型
        - 優先級
        - 原因
        - 現行狀況（AS-IS）
        - 變更後期望狀況（TO-BE）
        - 影響的頁面 / 程式
        - 影響程度
        - 期望完成日期
    - 選填欄位：相關問題單編號、相依性、附件、備註
    - 主管進行審核（核准 / 退回 / 需討論）
- ECR — 清單區：
    - 搜尋、優先級、狀態篩選
    - 統計數量顯示（待審核、已核准、實施中）
    - ECR 狀態：草稿、待審核、審核中、已核准、已退回、實施中、已完成
    - 編輯、刪除 ECR
    - 主管回填審核結果（核准 / 退回 / 需討論）與審核意見
- ECR 變更類型管理（⚙ 管理類型）：新增自定義變更類型、點擊改名、刪除（有 ECR 時阻擋）、拖移排序

### 訂閱方案（前台）

前台訂閱方案頁（`subscription.html`），並於帳號管理新增「訂閱管理」頁籤（`permissions.html`）。

- **方案卡片**：三欄顯示一般方案、月訂閱（$199/月）、年訂閱（$1,799/年），推薦方案有視覺標注
- **我的訂閱狀態**：顯示目前方案標籤、訂閱起訖日期、推薦碼
- **立即加入**：點擊「立即加入」彈出確認 Modal，確認後更新訂閱方案與日期，並自動產生推薦碼（`REF-XXXXX`）
- **取消訂閱**：已訂閱會員可點擊「取消訂閱」按鈕，跳出確認 Modal，確認後將方案改回一般方案（剩餘效期不退款，推薦碼保留）
- **方案按鈕邏輯**：已訂閱時，所有方案按鈕全部 disabled（不可點擊），僅能透過「取消訂閱」操作；一般方案不顯示「目前方案」標示，已訂閱方案顯示「訂閱中 ✓」
- **取消訂閱按鈕**：紅色警示樣式（`#dc2626`），附二次確認 Modal
- **推薦人機制**：輸入推薦碼後，雙方各完成至少一筆訂單，即可各獲得一張 $10 折價券（`COMP-XXXXX`，系統自動發放）；每人僅能使用推薦碼一次；被推薦人需先完成至少一筆訂單才能輸入推薦碼（前台不顯示此限制提示，後端仍執行驗證）
- **到期提醒**：前台公告首頁（`announcement.html`）在訂閱剩餘 ≤ 7 天時顯示橘色警示橫幅
- **訂閱狀態顏色**：未訂閱（灰）、月訂閱（藍）、年訂閱（金），統一於會員表格、Modal、前台 badge 使用
- **折扣方式**：月訂閱與年訂閱採固定金額折抵（每道餐點各減 $N 元），兩種方案折扣金額相同，差別僅在訂閱費用；預設折抵 $10 元
- **後台訂閱管理頁籤**：可設定每道餐點折抵金額、各方案訂閱費用（月訂閱 / 年訂閱各自獨立）、每日訂餐上限；收入統計分開顯示：月訂閱本月收入（月費 × 月訂人數）、年訂閱預付收入（年費 × 年訂人數，預付制全額顯示）

### 點餐（前台）

前台點餐頁（`order.html`），採左菜單 + 右側 sticky 購物車雙欄佈局，依會員訂閱狀態展示雙重價格。

- **佈局**：左側為菜單網格，右側為固定 sticky 購物車（320px），無需捲動即可操作；行動版自動改為單欄
- **餐點卡片**：含圖片佔位區與數量選擇器（`− N +`），選好數量後點「加入購物車」，Toast 顯示「已加入購物車」
- **已訂閱會員**：直接顯示折扣後的訂閱價（原價 − 折抵金額），附「訂閱價」青色（teal）標籤
- **未訂閱會員**：顯示原價，並列出訂閱後的折扣參考價（省 $N 元），引導升級
- **訂閱提示橫幅**：頁面頂部依訂閱狀態顯示對應說明文字，未訂閱者提供「查看訂閱方案」連結

- **會員模擬切換器**：右上角下拉可切換模擬會員（無訂閱 / 有訂閱），即時反映不同訂閱狀態的價格顯示差異；切換後頁面間共享選擇（`sessionStorage.fe_sim_member`），跨頁不重置；F5 重整全部資料回到預設狀態（sessionStorage 清空）
- **預設折價券**：無訂閱會員預設持有一張 $10 新會員贈券

### 點數 & 折價券管理（內部後台）

後台點數與折價券管理頁（`coupon.html`），以三 Tab 結構整合功能，預設開啟規則設定。

**Tab 1：規則設定**

- **點數規則設定**：可自訂每消費 $N 元得 M 點（預設每 $10 得 1 點）、每 X 點可兌換 $Y 折價券（預設 100 點換 $10），修改後點擊儲存即時生效

**Tab 2：促銷設定**

- **促銷列表**：顯示所有節日促銷（名稱、類型、期間、啟用狀態）；可切換啟用 / 停用或刪除
- **新增促銷**：填寫促銷名稱、選擇類型（點數倍數 / 直接發折價券）、設定活動期間、折價券有效期限與備註說明（支援多行輸入）；折價券補償類僅能從客訴管理發放，推薦類由系統自動發放

**Tab 3：資料管理**

- **點數 KPI**：全會員總點數、持有點數人數、可兌換折價券人數（點數達門檻）、累計兌換次數
- **折價券 KPI**：已發放張數、待使用張數、已使用張數、待折抵總金額
- **會員查詢**：表格顯示會員編號、姓名、持有點數、訂閱方案、持有折價券張數（未使用）、待折抵金額；支援依姓名或會員編號搜尋
- **折價券列表**：顯示折價券碼、折抵金額、持有會員、來源、備註、有效期限、發放日期、狀態；可依關鍵字、來源、狀態篩選；可作廢未使用折價券（附二次確認）
